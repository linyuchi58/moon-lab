# 🌙 日地月 3D 實驗室 v12

一個 3D 宇宙、三支攝影機：**太空看**、**站在台灣看天空**、**望遠鏡看月亮**，同一時刻同步變化。
按「🚀 飛進小人的眼睛」，鏡頭會從太空一路飛到台灣的小人身上再抬頭看天空，幫助學生連結「太空視角」與「地面視角」。

- 國小模式：方位、高度角、拳頭量高度、今天的軌跡、每天同一時間殘影、月出月沒（每天晚約 50 分鐘）
- 國中模式：月日夾角、「被照亮的一半」與「朝向地球的一半」
- 理想模型：地軸與月球軌道不傾斜、地月距離縮短、天空中的月亮放大；朔約在初一清晨（對齊課本：初八傍晚上弦、十五半夜滿月、廿三清晨下弦過正南）

## 🏆 挑戰測驗（v12.2）
- 15 種題型、每次隨機產生、選項打亂：望遠鏡辨月相、先預測再觀察、拖日期做出月相、軌道位置 A–D、數拳頭量高度角、月出每天晚 50 分、兩段式（答案＋理由）診斷迷思⋯
- 年級・班級・座號點選器（與其他遊戲共用）、老師可鎖定班級、排行榜只算最近 20 天
- 教師後台：專屬通行碼＋5 組額度、出題設定（程度／題數／概念）、全班概念與迷思診斷、CSV 匯出、連線檢查
- 學生連結：`?code=12345` 會直接帶入代碼
- 後端：萬用遊戲端 Code.gs v3.3（管理密碼不外流、修改與清空成績都要驗證）
