# 🌙 日地月 3D 實驗室 v12

一個 3D 宇宙、三支攝影機：**太空看**、**站在台灣看天空**、**望遠鏡看月亮**，同一時刻同步變化。
按「🚀 飛進小人的眼睛」，鏡頭會從太空一路飛到台灣的小人身上再抬頭看天空，幫助學生連結「太空視角」與「地面視角」。

- 國小模式：方位、高度角、拳頭量高度、今天的軌跡、每天同一時間殘影、月出月沒（每天晚約 50 分鐘）
- 國中模式：月日夾角、「被照亮的一半」與「朝向地球的一半」
- 理想模型：地軸與月球軌道不傾斜、地月距離縮短、天空中的月亮放大；朔約在初一清晨（對齊課本：初八傍晚上弦、十五半夜滿月、廿三清晨下弦過正南）

## 素材與授權

- 地球：NASA Blue Marble / Black Marble（公有領域）
